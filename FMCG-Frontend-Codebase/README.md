# FMCG Frontend Codebase

Next.js 14 App Router operations console for FMCG Insight 360, built with React 18, TypeScript, and Vanilla CSS design tokens.

---

## 📁 Source Layout

```text
src/
├── app/            # App router pages (dashboard, analytics, settings, audit, models, etc.)
├── components/     # UI components (AuditConsole, ModelRegistryManager, ProductCatalog, Sidebar)
└── lib/            # Typed API client, WebSocket managers, local history persistence
```

---

## 💻 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Open Console**:
   Navigate to [http://localhost:3000](http://localhost:3000)
